Boot programs

Hold SHIFT during the prompt to open the menu on the MPC. Otherwise the default starts. Boot thingy opens that menu now.

Install an app

The new app is used on the next boot when it is the default and SHIFT is not held. It must be an aarch64 Linux executable, a script whose first line runs sh or bash, or a zip of an autorun package. The zip keeps that package in its own folder.

Reboot MPC

Clears the boot counter so the updater stays closed, then reboots.
