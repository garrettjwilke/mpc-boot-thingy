Boot programs

Hold SHIFT during the prompt to open the menu on the MPC. Otherwise the default starts. Boot thingy opens that menu now.

Boot Edit

Turn catalog patches on to make one boot entry. Stock keeps its own patch set. Each saved entry shows up in the list above.

Install a program

The new program is used on the next boot when it is the default and SHIFT is not held. It must be an aarch64 Linux executable, a script whose first line runs sh or bash, or a zip of an autorun package. The zip keeps that package in its own folder.
